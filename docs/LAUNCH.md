# Поделиться Ebi_English

## Короткое описание

Тренажёр английского в браузере: 11 124 карточки, 300 колод, интервальные повторения, грамматика, чтение PDF/DOCX/TXT, аудио и разговор с ИИ.

## Текст для публикации

Сделал Ebi_English — приложение для ежедневной практики английского с интерфейсом и подсказками на русском.

В одном месте: 11 124 карточки, 300 колод, интервальные повторения, грамматика и чтение своих PDF, DOCX и TXT. Читаешь текст, сохраняешь незнакомые слова, возвращаешься к ним в повторениях. Для объяснений и разговорной практики можно подключить свой ИИ-сервис.

Базовые карточки работают локально: скачай проект и открой index.html. Для них не нужны аккаунт и установка. ИИ и внешние речевые сервисы подключаются отдельно и могут быть платными.
