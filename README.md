# GB English Cards

Тренажёр английского: карточки, повторение SM-2, грамматика, чтение PDF/DOCX/TXT и разговор с ИИ.

## Запуск

Открой `index.html` в браузере. Сервер не нужен: SQLite, база карточек и PDF worker включены в локальные файлы проекта. Сохраняй файлы проекта рядом со страницей.

Прогресс, собственные карточки, книги и настройки хранятся в `localStorage` этого браузера. Экспорт прогресса в `english-progress.sqlite` переносит учебную статистику; книги, собственные карточки и ключи в этот файл не входят. Перед переносом страницы в другую папку или браузер экспортируй прогресс.

Для авторизованного ИИ-сервера введи свой ключ в настройках. Предустановленного ключа нет. Ключи сохраняются в браузере; скрытие символов в поле не является шифрованием. Запросы перевода, ИИ и распознавания речи отправляют соответствующий текст или звук выбранному сервису. Базовые карточки работают без этих сервисов.

Консольная версия: `python main.py`. Она использует отдельный `vocabulary.json` и сохраняет собственный прогресс в `progress.json` рядом со скриптом.

## Проверки

Нужны Python 3.10+ и Node.js 20+ с npm. Команды ниже подходят для PowerShell и CMD:

```powershell
npm ci
npx playwright install chromium --only-shell
npm run test:all
```

`npm test` проверяет отсутствие ключей/личных файлов в исходниках и Git-истории, затем запускает проверки JavaScript и 22 проверки Python. `npm run test:all` дополнительно выполняет по 43 браузерных сценария через `file://` и локальный HTTP. Профили, документы и прогресс тестовые; внешние сервисы подменяются или блокируются. Артефакты создаются в `dev/audit-artifacts/`. Эти же команды включены в GitHub Actions для Windows.

Отдельный прогон через HTTP автоматически запускает временный сервер на свободном порту и закрывает его после проверки:

```powershell
npm run test:browser:http
```

При желании страницу можно раздавать обычным статическим сервером или GitHub Pages; сборка приложения не требуется. В Firefox, Safari и на физических мобильных устройствах полный набор пока не запускался. Внешние ИИ/STT-сервисы и микрофон требуют отдельной проверки с твоими настройками.

## Основные файлы

- `index.html` — интерфейс и логика браузерного приложения.
- `content.db`, `content-db-b64.js` — статичная база: 300 колод, 11 124 карточки.
- `sql-wasm.*`, `sql-wasm-b64.js` — SQLite в браузере.
- `pdf.min.mjs`, `pdf.worker.min.mjs`, `pdf-lib-b64.js`, `pdf-worker-b64.js`, `mammoth.browser.min.js` — чтение документов. PDF.js 6.4.299 работает и при локальном открытии страницы.
- `marked.min.js`, `purify.min.js` — Markdown и очистка HTML.
- `freedict.js` — словарь подсказок.
- `import_*.py`, `patch_content_db.py`, `fix_content_translations.py` — сборка и исправление контента.
- `dev/test_audit.js`, `dev/test_project_audit.py` — регрессии аудита.
- `dev/context_grammar.json` — собственные упражнения с пропусками для A2–B2.
- `vendor-manifest.json`, `licenses/` — версии, контрольные суммы, лицензии и атрибуции сторонних материалов.
