# Ebi_English

**Повторяй слова, читай интересные тексты и практикуй разговор — в одном приложении.**

Ebi_English — тренажёр английского для русскоязычных пользователей: **11 124 карточки в 300 колодах**, интервальные повторения, грамматика, чтение документов, аудио и необязательный ИИ-преподаватель. Интерфейс и подсказки на русском.

Название репозитория — **Ebi_English**. В интерфейсе сохранено авторское название **«Грет британ блть»** и логотип **GB English**.

## Что внутри

| Практика | Возможности |
|---|---|
| Словарный запас | Колоды по уровням, собственные карточки, переводы и примеры |
| Повторение | Алгоритм SM-2, повторение по сроку, работа над ошибками и статистика |
| Грамматика | Задания с пропусками, проверка ответов и упражнения по темам |
| Чтение | Импорт PDF, DOCX и TXT, поиск незнакомых слов и сохранение карточек |
| Аудирование | Аудиопримеры, диктант и речевые возможности браузера |
| Разговор и ИИ | Объяснения преподавателя, диалоги на английском и перевод через выбранный сервис |
| Тематический английский | Научные материалы и информационная безопасность |

Предложенный ежедневный маршрут: **7 минут повторения, 7 минут чтения, 6 минут разговора**. После скачивания базовые карточки работают локально. ИИ, внешнее аудио и речевые сервисы требуют подключения к Интернету; некоторым нужен собственный ключ.

## Быстрый запуск

1. [Скачай проект](https://github.com/madnessbrainsbl/Ebi_English/archive/refs/heads/main.zip) и распакуй ZIP.
2. Открой `index.html` в Chromium, Chrome или Edge. Сохраняй файлы проекта рядом со страницей.
3. Начни урок или выбери тему. Для базовых занятий не нужны аккаунт, установка и сборка.

Можно сразу [открыть приложение онлайн](https://madnessbrainsbl.github.io/Ebi_English/). Для локальной работы скачай проект: онлайн-версия сама по себе не устанавливает офлайн-копию.

SQLite, база карточек и PDF worker включены в локальные файлы. Сервер для локального запуска не нужен.

## Прогресс и перенос данных

Прогресс, собственные карточки, книги и настройки хранятся в `localStorage` текущего браузера. Перед переносом страницы в другую папку, сменой браузера или переходом между локальной и онлайн-версией экспортируй прогресс.

Экспорт в `english-progress.sqlite` переносит учебную статистику. Книги, собственные карточки и ключи в этот файл не входят — сохраняй их отдельно, если переносишь приложение.

## ИИ и голосовые сервисы

Введи свои настройки сервиса и ключ в приложении. Предустановленного ключа нет; использование провайдера может быть платным. Ключи сохраняются в браузере, а скрытие символов в поле не является шифрованием.

Для чата с Groq: открой **«Чат» → «Настройки ИИ» → «Groq»**, вставь свой API-ключ, выбери модель и нажми **«Проверить и сохранить»**. Настройки сохраняются после успешной проверки. При смене сервиса поле ключа очищается; отмена не меняет сохранённое подключение. Распознавание речи Groq Whisper настраивается отдельно в разделе **«Голос»** на главной странице.

Запросы перевода, ИИ и распознавания речи отправляют соответствующий текст или звук выбранному сервису. Базовые карточки работают без этих подключений.

## Консольная версия

Нужен Python 3.10+:

```powershell
python main.py
```

Консольный тренажёр использует отдельный `vocabulary.json` с меньшим набором карточек и сохраняет собственный прогресс в `progress.json` рядом со скриптом. Он не синхронизируется с браузерной версией.

## Проверки для разработчиков

Нужны Python 3.10+ и Node.js 20+ с npm. Команды подходят для PowerShell и CMD:

```powershell
npm ci
npx playwright install chromium --only-shell
npm run test:all
```

Набор включает проверки JavaScript, 22 теста Python и по 44 браузерных сценария через `file://` и HTTP. Проверяются сохранение прогресса, импорт документов, уроки, адаптивный интерфейс и состав публикации. Используются изолированные браузерные контексты и синтетические документы; внешние сервисы подменяются или блокируются.

Отдельные команды:

```powershell
npm test                    # JavaScript, Python и проверка состава публикации
npm run test:browser        # Браузерные сценарии при локальном открытии
npm run test:browser:http   # HTTP-сценарии с временным сервером
```

HTTP-прогон сам запускает сервер на свободном порту и закрывает его после проверки. Артефакты создаются в `dev/audit-artifacts/`. GitHub Actions выполняет проверки на Windows.

Полный набор пока не запускался в Firefox, Safari и на физических мобильных устройствах. Реальные ИИ/STT-сервисы и микрофон требуют отдельной проверки с твоими настройками.

## Основные файлы

- `index.html` — интерфейс и логика браузерного приложения.
- `content.db`, `content-db-b64.js` — статичная база: 300 колод, 11 124 карточки.
- `sql-wasm.*`, `sql-wasm-b64.js` — SQLite в браузере.
- `pdf.min.mjs`, `pdf.worker.min.mjs`, `pdf-lib-b64.js`, `pdf-worker-b64.js`, `mammoth.browser.min.js` — чтение документов.
- `marked.min.js`, `purify.min.js` — Markdown и очистка HTML.
- `freedict.js` — словарь подсказок.
- `main.py`, `vocabulary.json` — консольная версия.
- `import_*.py`, `patch_content_db.py`, `fix_content_translations.py` — сборка и исправление контента.
- `dev/` — регрессионные проверки и собственные упражнения.
- `vendor-manifest.json`, `licenses/` — версии, контрольные суммы, лицензии и атрибуции сторонних материалов.
